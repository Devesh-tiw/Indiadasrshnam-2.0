# BharatDarshnam 2.0 🕉️🏔️

> **India's Cultural, Spiritual & Alpine Discovery Engine**  
> A Next-Gen React, Tailwind CSS, Lucide & Leaflet interactive travel intelligence platform.

---

## 🌟 What's New in BharatDarshnam 2.0

1. **Brand Modernization**:
   - Clean, luxury dark/light glassmorphic UI.
   - Removed all clutter and badges from the navigation bar for an enterprise-grade experience.

2. **Expanded Categories**:
   - 🕉️ **Spiritual & Mandir**: Kedarnath, Kashi Vishwanath, Yamunotri, Gangotri, Badrinath, Mahakaleshwar, Omkareshwar, Tirupati, Chidambaram.
   - 🏔️ **Hills & Mountains**: Manali, Shimla, Rishikesh, Munnar, Ooty Nilgiris.
   - 🥾 **Trekking & Himalayan Trails**: Triund Ridge, Valley of Flowers.
   - 🏰 **Forts & UNESCO Heritage**: Hampi, Mehrangarh Fort Jodhpur, Brihadeeswarar Temple Thanjavur.
   - 🌿 **Nature & Wildlife**: Jim Corbett National Park, Wayanad Wildlife Sanctuary.

3. **Interactive Pre-Mapped Yatra Circuits**:
   - Uttarakhand Himalayan Char Dham Circuit (1,450 km)
   - Sacred Northern 12 Jyotirlinga Trail (1,820 km)
   - Himachal Alpine Valley Loop (920 km)
   - Great Living Chola Temples Trail (430 km)
   - Western Ghats Mist & Tea Trail (650 km)

4. **Dedicated Verified Stays & Hotel Hub**:
   - Proximity-based stay recommendations (OYO Townhouse, OYO Flagship, OYO Home, and Boutique Ashrams).
   - Amenity tags (Temple View, Geyser, Satvik Dining, AC, WiFi).
   - Multi-OTA links (Booking.com, MakeMyTrip, RedBus transit).

5. **AI Pilgrimage & Mountain Itinerary Planner**:
   - Dynamic day-by-day generator with origin city, route duration, stay budget calculation, and confetti celebration.

6. **1-Minute Audio Guide**:
   - Native Web Speech synthesis narration with speed controls (0.8x, 1.0x, 1.2x) and visual waveform.

7. **Live GPS Road Distance**:
   - Real-time road routing via OSRM with 1-click Google Maps turn-by-turn navigation.

8. **Wishlist / Saved Places**:
   - LocalStorage backed bucket list for travelers.

## 🚀 Quick Setup & Run Locally

```bash
# 1. Enter the project directory
cd indiadarshnam-app

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev

# 4. Build for production (GitHub Pages / Vercel / Netlify)
npm run build
```
